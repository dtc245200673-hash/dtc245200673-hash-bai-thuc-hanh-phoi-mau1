# Bài thực hành phối màu đơn tông HTML/CSS

- `index.html`: phiên bản tông xanh theo mã màu trong đề (#00ADEE, #00BFF2, #BDD7F7, #C6E9FA).
- `phien-ban-2.html`: phiên bản phối màu đơn tông tím khác.

## Chạy
Mở `index.html` bằng trình duyệt. Chọn `Phối màu 2` để xem phiên bản còn lại.

## Nộp bài
Tạo repository mới trên GitHub, tải ba file lên và dán URL repository vào ô nộp bài.

**Lưu ý:** Đây là trang web mẫu mới được xây dựng theo các chỉ dẫn phối màu của bài tập, không phải mã nguồn chỉnh sửa trực tiếp từ file Pra.zip gốc.
